# iPhone 17 の良い点・悪い点

## 良い点

- **マクロレンズが便利 **  
  これは 13 以降からある機能だそうですが、以前使用していた Pixel 7 では、被写体がドアップの状態ではピントが全く合いませんでした。その点 iPhone はドアップにすると自動でマクロモードに切り替えてくれます。ドアップでもピントの合った写真の撮影が可能です。
- **Face ID が便利 **  
  これが何より気に入っています。これまでの Pixel 7 では指紋認証が基本でしたが、画面内指紋認証のため非常に精度が悪く、10回に1回通るかどうかレベルで、結局いつも PIN 入力にしていました。その点、iPhone の Face ID は便利です。ロック解除もアカウントログインも全て顔パスで一瞬です。しかも赤外線なので、真っ暗闇でも顔認証できます。マスク、メガネにも対応しているのも素晴らしいです。
  （正確には Pixel 7 にも顔認証システムはあるんですが、3D 認証に対応していないなどの技術的制約により画面ロック解除など一部にしか使えないのです）
- **Apple 端末同士の連携が便利 **  
  Apple 製品の醍醐味。iPad や MacBook を持っていると、連携機能が非常に便利です。AirDrop はもちろんのこと、Wi-Fi パスワードの共有や画面ミラーリングなどもシームレスに行えます。
- **Dynamic Island が地味に便利**  
  あの内カメラ周辺にある黒いエリアですね。以前は切り欠き型の「M字ハゲ」なんて揶揄されていましたけど、最近はこの周辺にアイコンなどが表示されるようになって、邪魔だと思っていたものが意外に便利に感じています。例えば Spotify で再生中に別のアプリを開いたとき、ここに再生中の番組名などが表示され、タップすると Spotify に戻ることが可能です。

## 悪い点

- **楽天 Edy が Apple Pay に対応していない**  
  正直悪い点はそこまで見つかっていないのですが、強いて言うならこれです。楽天 Edy は Android 端末のおサイフケータイでは利用可能なのですが、Apple Pay には対応しておらず。リクルートカードからのチャージで還元率が高かったので日常利用していたのですが、今後は物理カードへのチャージが必須になってしまいました。
- **思ったより電池の持ちは良くない（Pixel 7 比） **   
  これはまだ購入直後なので最適化中の可能性はあります。が、今のところ以前の Pixel7 と比べて特段「電池の持ちが良くなった」と感じるレベルではありません。外出でよくカメラを使う日には特に電池の消費が激しく、新品にも関わらず夕方にはモバイルバッテリーからの充電が必須です。一方、平日の出勤日など一日数時間程度（行き帰りの電車など）しか画面を見ない場合は、2日間充電せずとも余裕で持ちます。普段遣いには十分な一方、外出日には要注意です。もちろん、バッテリーが経年劣化していた前機種に比べたら遥かにマシですが、思ったほどのサプライズはない印象です。
- **Windows のスマートフォン連携が使えない**  
  まあこれは Microsoft の問題ですが…。Windows 11 には Android スマホとの連携機能があり、有線で繋がなくとも写真のコピーなどが出来ます。が、iPhone は対応していません。その代わりに Mac とだったら同じようなことが出来ます。いい加減仲良くしてほしいものです。

# なぜ iPhone にしたのか

Android 派の方々からすれば、おいおいなんで Pixel から iPhone に乗り換えたんだよ、と思われるかもしれません。

理由は2つあります。

## 理由1. そもそも交互に買う主義だから

私は iOS と Android を平等に愛しています。どちらも大好きです。

これまでも Nexus 6P → iPhone 7 → Pixel 7 → iPhone 17 と乗り換えてきました。

両刀派だからこそ、Android の次は iPhone と元々決めていたのです。ですので、数年後は間違いなく Android 端末を購入すると思います。

もちろん、Pixel 7 も起動しなくなるまではサブ端末として今後も活躍してもらうつもりです。

### iPhone と Android スマホを交互に購入するメリット

ずばり「それぞれの長所と短所を補える」ことだと思います。

これは「iPhone と Android スマホを同時に2台持ちする」ケースに限られるので、下取りに出したりレンタルの場合は該当しませんが、iPhone と Android を両方持っていれば、世の中の 99.9% のスマホアプリは使えます。日常的に使うほとんどのサービスは両方に対応していますが、ニッチなところで一方しか対応していなかったり、一方が使い勝手が悪かったり、一方でしかサービスやキャンペーンが展開されなかったりするものです。

例えば、自分の使用環境でも見受けられた差異として

- 楽天 Edy は Apple Pay に対応していない（前述）
- Linux ターミナルが利用可能な「Linux 開発環境」（Android Virtualization Framework）は Pixel でしか使えない
- Android のほうが気軽に自作アプリをテストできる
- コーヒーメーカーのネスカフェ ドルチェグストはスマホからコーヒーを淹れることができるが、Android 版は出来が悪くマシンに接続できないことが多い
- その他のアプリも iOS 版は優先的にバグ修正に対応してもらえるのに対し、Android 版は後回しにされがち（特に国内サービス）
- アクセサリ類は iPhone 向けのほうが圧倒的に多い

などなど…

ですから、iPhone と Android を交互に購入することで、（少なくとも一方が壊れるまでは）常に2台持ちとして両方の良いとこ取りができるわけです。

私は PC においても「デスクトップは Windows、ラップトップは Mac、サーバは Linux」というポリシーで購入しています。

様々な OS に触れること = 可能性を広げることに繋がるのです。ですから、不毛な OS 論争は今すぐ止めて皆さんも両刀派になりましょう。（お金はかかりますが）

## 理由2. iPhone 値上げの噂があったから

事の発端は先月、CEO の Tim Cook 氏が WSJ のインタビューに「残念ながら、値上げは避けられない」と発言したことに始まります。

ここから数日後、本当に Mac と iPad が値上げされてしまいました。

この時点ではまだ iPhone は値段据え置きでした。

が…

# まとめ

3年半ぶりに iPhone に戻ってきたときの感想でした。正直、iPhone 17 も Pixel 7 も完成度の高いスマホなので、ことカメラに関しては iPhone 7 → Pixel 7 に移行したときほど驚きはありませんでしたが、（上にも書きましたが）3年分の進化としては妥当だと思います。どちらかといえば Face ID や iPad, Mac との連携など、普段遣いの面で利便性が向上したかなと思います。

スマホの高騰が続いています。長年使えるよう大切に使っていきたいと思います。
